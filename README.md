# راست‌خوان

راست‌خوان افزونه‌ای برای Chrome و Edge است که جهت خواندن بندهای فارسی و انگلیسی را در صفحات وب تنظیم می‌کند. در حالت خودکار، بندی مثل «API را به‌روز کن» از راست و بندی مثل «Check the output» از چپ شروع می‌شود. از منوی افزونه می‌توان حالت «همیشه راست‌به‌چپ» را هم انتخاب کرد.

## نصب

1. فایل `rastkhan.zip` را از [صفحهٔ انتشار](https://github.com/MHMK2002/rastkhan/releases/latest) دانلود کن و از حالت فشرده خارج کن.
2. در Chrome آدرس `chrome://extensions` یا در Edge آدرس `edge://extensions` را باز کن.
3. **Developer mode** را روشن کن، **Load unpacked** را بزن و پوشهٔ `rastkhan` را که حاوی `manifest.json` است انتخاب کن.
4. تب‌های باز را تازه‌سازی کن. با کلیک روی آیکون افزونه می‌توانی حالت خواندن را عوض کنی یا افزونه را خاموش کنی.

اگر مخزن را کلون کرده‌ای، پوشهٔ `rastkhan` داخل مخزن را مستقیماً در مرحلهٔ سوم انتخاب کن.

## کد در Markdown

کدهای داخل جمله و بلوک‌های کد از چپ به راست نمایش داده می‌شوند. در نمونه‌هایی مثل کاتلین با توضیح فارسی، تورفتگی خط‌ها حفظ می‌شود و علامت `//` پیش از توضیح می‌آید. این رفتار در هر دو حالت خواندن فعال است.

## حریم خصوصی

تشخیص جهت متن داخل مرورگر انجام می‌شود. افزونه فقط وضعیت روشن یا خاموش بودن و حالت خواندن را در حافظهٔ محلی مرورگر ذخیره می‌کند.

## اجرای آزمون

با نصب Node.js و Chrome، این دستور را از ریشهٔ مخزن اجرا کن. آزمون، افزونه را در یک نمایهٔ موقت Chrome بارگذاری می‌کند و چیدمان کد، اسکرول افقی و متن فارسی را بررسی می‌کند. برای انتخاب فایل اجرایی مرورگر می‌توانی متغیر محیطی `CHROME_BIN` را تنظیم کنی.

```sh
node --test tests/markdown.test.mjs
```
